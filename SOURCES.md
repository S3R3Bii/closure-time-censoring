# Primary sources and discovery boundary

- [Official NYC 311 dataset](https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9); [machine-readable schema](https://data.cityofnewyork.us/api/views/erm2-nwe9.json). The schema defines creation and closure dates and responding agency; the dataset covers agency-directed service requests, is updated daily and warns that expected field values change. Discovery metadata timestamp rowsUpdatedAt=1793237699; full retrieval must read fresh version metadata before/after.
- [NYC Open Data FAQ](https://www.nyc.gov/opendata/get-started/FAQs): no restrictions on use of open data. [Portal terms](https://data.cityofnewyork.us/stories/s/Terms-of-Use/k9k7-3cje): agencies remain authoritative; data may be corrected, overwritten/refreshed and older versions are not retained; no completeness/fitness warranty. Do not claim actual historical information availability.
- [Official dataset update note](https://www.nyc.gov/opendata/news/all-news/311-Service-Requests-Updates): the portal split 2010–2019 from 2020–present and renamed visible Problem/Problem Detail labels while preserving API field names. Neither field nor new Additional Details is requested in this study.
- [Socrata endpoint documentation](https://dev.socrata.com/foundry/data.cityofnewyork.us/erm2-nwe9): official public JSON query endpoint. Use bounded sequential pages and ordinary limits; no credential or access-control workaround.
- [R survival manual: restricted mean](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/print.survfit.html) and [curve summary/extension cautions](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/summary.survfit.html): fixed truncation permits comparable restricted means; carrying a positive tail past unsupported follow-up can be biased. The implementation will use exact Python arithmetic and independent SQL/decimal checks; R execution is not claimed.

Before this protocol, metadata, one development-day record's field types and twelve source-coverage counts were checked. A broad grouped count query timed out; simpler indexed agency/month counts succeeded. Coverage totals 273, 641 requests, each agency/month containing 15, 056–28, 259. No status/closure distribution, KM, restricted mean or benchmark error was computed. Sources and one metadata record remain in private discovery receipts; no source query chosen on its closure outcomes.

Product-limit survival, restricted means and completed-case bias are established ideas. The bounded contribution is an executed, reproducible timing/endpoint comparison with full cohort results. No novel method, exhaustive prior-work review, human-audited resolution label or prospective service-performance claim.
